# ADR 0003: PostgreSQL + Prisma

**Дата:** 2026-04-18
**Статус:** принято

## Решение

Основная БД — **PostgreSQL 16**, ORM — **Prisma**.

## Причины

- PostgreSQL — де-факто стандарт для маркетплейсов: JSONB, полнотекстовый поиск, PostGIS для гео, транзакции.
- Prisma — типобезопасный клиент, декларативные миграции, хорошая интеграция с TS.
- `packages/db` выносит Prisma-клиент в общий пакет → web/admin/api используют один набор типов БД.

## Альтернативы

- **Drizzle** — легче, но экосистема и миграции пока слабее Prisma.
- **TypeORM** — тяжёлый, устаревшие паттерны.
